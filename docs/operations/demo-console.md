# Investigation demonstration console

Run the deterministic investigation demonstration locally:

```bash
uv run sentinel-investigate-demo
```

The console reads `tests/fixtures/investigation_evidence.json` by default. A different typed evidence fixture can be supplied with `--evidence path/to/evidence.json`. It displays the evidence count, deterministic summary, matching runbook recommendations, and makes clear that no hypotheses are generated by this workflow.

This console is a local demonstration surface, not a production investigator UI.
